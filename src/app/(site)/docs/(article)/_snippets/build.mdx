## Serve Your CareerChive

::: {.tabset}

# Build Application Locally

To build the application locally for private use:

```bash
# Linter check for errors
npm run lint
# Compile
npm run build
# Serve build 
npm run start
```

# Deploy to Vercel

::: {.callout}
# {.lock} If you deploy your application Vercel or another platform, make sure you gate your application behind a login.

Otherwise, anyone who can access your install of CareerChive can spam your Supabase database or perform irreversible destructive actions.

:::

The easiest way to do this is just to connect your CareerChive GitHub repository to a Vercel project.

From your [Vercel](https://vercel.com/){.blank} dashboard:

1. If you already have projects with Vercel, click **Add New** and select **Project**.

    ::: {.callout}
    If you've just freshly signed up for Vercel, select **GitHub** under Import Git Repository on your main page:

    - Follow the prompts to authorize the connection to your GitHub account.
    - You can allow Vercel to access all your repositories, or just the one you want to deploy.

    :::

2. Click **Import** for your CareerChive repository, then set the **Project Name**.

    Your project name will become the URL slug for your application if it's unique and available.

3. Click **Environment Variables** to enter the following [variables](https://vercel.com/docs/environment-variables){.blank}:

    ```bash
    # Supabase project URL
    NEXT_PUBLIC_SUPABASE_URL=https://<your-database-url>.supabase.co

    # Supabase publishable key (browser-safe, RLS still applies)
    NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_<your-publishable-key>

    # Server Data API secret. (Never NEXT_PUBLIC_)
    SUPABASE_SECRET_KEY=sb_secret_<your-secret-key>

    # Gate CareerChive behind login
    FLAG_PRIVATE=true

    # Session secret for login authentication
    SESSION_SECRET=<your-generated-value>

    # Cloudflare Account ID
    CLOUDFLARE_ACCOUNT_ID=<your-account-id>

    # Cloudflare R2 Bucket  
    R2_BUCKET=<your-bucket-name>  

    # Cloudflare R2 Access Key ID
    R2_ACCESS_KEY_ID=<your-access-key-id>
    
    # Cloudflare R2 Secret Access Key
    R2_SECRET_ACCESS_KEY=<your-secret-access-key>

    # Cloudflare R2 Endpoint
    R2_ENDPOINT=https://<CLOUDFLARE_ACCOUNT_ID>.r2.cloudflarestorage.com
    ```

:::
