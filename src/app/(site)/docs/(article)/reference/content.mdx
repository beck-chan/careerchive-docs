# Docs Reference

To render only the documentation for previewing:

```bash
npm run docs
```

::: {.callout}
# To create a new documentation page, copy an existing `page.tsx` next to a `content.mdx` into a directory named for the page URL slug under `src/app/docs/(article)/`.

Navigation with specific defined sections linked to the main documentation landing page is defined in `src/app/docs/_nav/docs-nav-data.ts`.
:::

## YAML Frontmatter

```yaml
---
subtitle: Set an optional subtitle
search: false # Hide page from docs search

# h1 sets the page title and browser tab
---
```

## Single-Sourcing

Shared prose lives in `_snippets/`. Import a snippet to use it on a page:

```markdown
import Example from "../_snippets/example.mdx"

<Example />
```

::: {.callout}
<Example />
:::

Leave YAML and `# h1` on the host page. Snippet `##` / `###` headings are included in the host table of contents automatically, in the order the snippet appears on the page.

## Content

### Headings

The table of contents is built from `##` and `###` headings.

### Callouts

::: {.callout}

# A `#` heading inside a callout is styled like `###` and does not appear in the table of contents.

Use a `::: {.callout} :::` for a note that should sit apart from the main text. Indent the fence under a list item to nest the callout in that step.

:::

### Tables

Pipe tables use a header row, a `| --- |` separator, and body rows:

| Data | Who | Purpose |
| --- | --- | --- |
| Organization name and date range | Anyone with the archive | Group daily entries |
| Daily attendance, work, notes, and ratings | The person logging | Track that day's record |
| Search queries and ChiveBot summaries | The person searching | Find and recap logged days |

Align a column with `:---` (left), `:---:` (center), or `---:` (right) in the separator row.
