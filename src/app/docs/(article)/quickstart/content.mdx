## Setting Up

### Grab CareerChive Repository

::: {tabset}

# Via GitHub

::: {.columns}

::: {.80}

    Fork [`https://github.com/beck-chan/career-chive/`](https://github.com/beck-chan/career-chive/){.blank} on GitHub, then clone *your* copy into your local environment:

:::

::: {.20}

[Fork on GitHub](https://github.com/beck-chan/career-chive/fork){.button .blank}

:::

:::

```bash
git clone https://github.com/YOUR_USER/career-chive.git
cd career-chive
# Install dependencies
npm install
```

# Via CLI

With the [GitHub CLI](https://cli.github.com/){.blank} installed and signed in (`gh auth login`):

```bash
# Fork to your account and clone in one step
gh repo fork beck-chan/career-chive --clone
cd career-chive
# Install dependencies
npm install
```

:::
