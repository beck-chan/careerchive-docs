# View Analytics

<Prereq />

## Use Analytics Overviews

::: {.callout}
Analytics are only displayed for dates within the organization's Active Date range and Archive Start range.
:::

Click **Overview** in the top navigation bar to view analytics on your daily logs for tracked organizations.

1. Select an organization from the left sidebar to view associated overviews.

2. From **Period**, select a period to view analytics for.

## Export Data

### Export Completed Work

If there is Completed Work for the selected period, you can export those items as a CSV file:

1. Under Work Completed, click **Export**.

2. Check off the items to include in the export.

3. Click **Export Work**.

### Export Citations & Artifacts

If there are Citations or Artifacts for the selected period, you can export those items as a CSV file:

1. Under Citations / Artifacts, click **Export**.

2. Check off the items to include in the export.

3. Click **Export Citations & Artifacts**.

    ::: {.callout}
    Attachments are a link to the file in your Cloudflare R2 bucket.
    
    :::
