# Use Search

<Prereq />

## Basic Search

::: {.callout}
Search results and ChiveBot responses are only displayed for dates within the organization's Active Date range and Archive Start range.
:::

1. Click **Search** in the top navigation bar to search your daily logs.

2. Type queries into **Search Keywords**.

### Sort & Filter Results

Narrow down the results returned by:

::: {.tabset}

# Organizations

Filter the organizations to return results for.

# Date Range

Filter by date range to return results for.

# Attendance

Filter by attendance type to return results for.

# Contents

Filter by whether or not citations / artifacts, notes, or comments are contained in results.

:::

## Ask ChiveBot

::: {.callout}
# ChiveBot responses are only displayed for dates within the organization's Active Date range and Archive Start range.

To use ChiveBot, you must [Enable CareerChive Chatbot](/docs/chatbot).
:::

ChiveBot will search your entries and provide a response if it finds relevant information:

1. Click **Search** in the top navigation bar.

2. Enter a question into **Ask ChiveBot about your archive ...**.

3. Click **Send**.
