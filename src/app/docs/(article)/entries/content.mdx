# Log & Manage Entries

<Prereq />

## View Logs

Click **Archive** in the top navigation bar to view logs for all tracked organizations.

1. Select an organization from the left sidebar to view associated daily logs.

2. Select a date from the date picker to view the daily log for that date, or:

    - Click **Open Today** to view the daily log for the current date. If no log has been created for that date, but it is within the organization's active date range and archive start date, you will be prompted to create an entry.
    - Click **Open Most Recent** to view the daily log for the most recent date.

## Enter & Edit Logs

::: {.callout}
Logs can only be created for dates within the organization's Active Date range and Archive Start range.
:::

Click **Archive** in the top navigation bar to enter and edit logs, or create backfilled logs for past dates not auto-generated within your Archive Start date and organization's Date Active range:

1. Click on an organization's name in left sidebar to view associated daily logs.

2. Select a date from the date picker to view the daily log for that date.

    If no log has been created for that date, but it is within the organization's active date range and archive start date, you can create a backfilled log by clicking on the date.

3. Enter or update the log's details: 

::: {.tabset}

# Attendance

1. Select the attendance status for the day:

    - **worked** — You worked that day.     
    - **sick day** — You were sick and missed work that day.
    - **stat holiday** — You were on a statutory holiday that day.
    - **PTO** — You were on paid time off and did not work that day.

2. Click **Save**.

# Work Completed

1. Click **+ Add Work** to enter an item of work you completed that day.

2. Enter the item's details:

    - **Title** — The title of the item.
    - **Description** — The description of the item.
    - **Link** — A link to the item.

3. Click **Save**.

::: {.callout}
# When you have more than one item entered, drag and drop to reorder items. 

Changes to order are automatically saved.
:::

# Citations / Artifacts

1. Click **+ Add Citation / Artifact** to enter supporting entry items for work completed that day.

2. Enter the item's details:

    - **Title** — The title of the item.
    - **URL** — A link to the item.
    
    Click **Upload Attachment** to attach a file to upload to the item:

        a. Select the file to upload.
        b. Click **Save**.

3. Click **Save**.

::: {.callout}
# When you have more than one item entered, drag and drop to reorder items. 

Changes to order are automatically saved.
:::


# Notes

Use the rich text editor to enter your work related-notes for the day.

# Rating

1. Select the rating for the day: 

    - **awful** — You felt terrible that day.
    - **poor** — You felt not good that day.
    - **okay** — You felt mid that day.
    - **good** — You felt nice that day.
    - **great** — You felt amazing that day.

2. Click **Save**.

# Comments

Use the rich text editor to enter your other comments for the day.

## Clear & Delete Logs

::: {.callout}
To manage bulk clearing of data and deletion of logs, refer to [Settings & Organizations](/docs/settings).

:::

Click **Archive** in the top navigation bar to clear data and delete a log for a specific date.

### Clear All Data

::: {.callout}
# Clearing all data will remove all data for that day, including work completed, citations, notes, and comments.

Clearing data is irreversible — proceed with caution.
:::

1. Click on an organization's name in left sidebar to view associated daily logs.

2. Under Manage, select **Clear All**.

3. Click **Clear** to confirm removal of all data for that log.

### Delete a Log

::: {.callout}
# Deleting a log will remove all data for that day, including the log itself.

Data is irrecoverable, but you can always recreate the log by backfilling if needed — proceed with caution.
:::

1. Click on an organization's name in left sidebar to view associated daily logs.

2. Under Manage, select **Delete Day**.

3. Click **Delete** to confirm removal of the that day's log.
